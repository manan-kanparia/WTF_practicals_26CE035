01

Timers: setTimeout() and setInterval()

See the difference between an action that happens once and an action that repeats.

TRY IT

Click a button to begin.
setTimeout = once • setInterval = repeatedly • clearInterval = stop

JAVASCRIPT CODE

setTimeout(function(){
    result.textContent = "Offer unlocked!";
}, 2000);

let timer = setInterval(function(){
    result.textContent = "New message";
}, 2000);

clearInterval(timer);
02

Callback Function

A callback is a function given to another function, to be called when the task finishes.

TRY IT

Step 0: Waiting for a request.
A demo only. No real travel booking is created.

JAVASCRIPT CODE

function processRequest(place, callback){
    setTimeout(function(){
        callback("Request for " + place + " done!");
    }, 1500);
}

processRequest("Goa", function(message){
    result.textContent = message;
});
03

Fetch API + JSON + Error Handling

Load a JSON list using fetch(), display its records and catch a deliberately invalid JSON response.

TRY IT

No data loaded yet.
The demo fetches a temporary local Blob URL. In the student project, fetch("packages.json") reads the separate file through Live Server.

JAVASCRIPT CODE

fetch("packages.json")
.then(function(response){
    if(!response.ok) throw new Error("Load failed");
    return response.json();
})
.then(function(packages){
    // Display package cards using DOM
    console.log(packages);
})
.catch(function(error){
    result.textContent = error.message;
});

Local Storage: Remember Preferences

Local Storage remembers your destination and theme after refreshing this page.

TRY IT

Preferences not saved.

JAVASCRIPT CODE

localStorage.setItem("destination", "Goa");

localStorage.removeItem("destination");

// Data normally survives a page refresh.
05

Session Storage: Temporary Guest Name

Session Storage remembers information in this browser tab's session, including across reloads.

TRY IT

No temporary name stored.
Data is not sent anywhere; it stays in browser storage.

JAVASCRIPT CODE

sessionStorage.setItem("guest", "Aarav");

let name = sessionStorage.getItem("guest");

sessionStorage.removeItem("guest");

// Saved for the current tab's session.
